# FB Bridge (MediaScanner)

Расширение Chrome для отдельного профиля с аккаунтом Facebook. Читает ленты
целевых страниц и групп Facebook организаций с подпиской и отправляет посты в
бэкенд MediaScanner (задача 384). Отдельное от IG Bridge (Instagram).

Как работает:

1. Раз в минуту расширение спрашивает у бэкенда следующий источник
   (`POST /api/internal/facebook-bridge/next/`, заголовок `X-FB-Bridge-Token`).
2. Открывает его в закреплённой вкладке facebook.com (группы в хронологическом
   порядке). Вкладка остаётся фоновой.
3. Забирает посты из данных страницы и дозапрашивает до трёх следующих порций
   ленты тем же запросом, что сайт делает при прокрутке
   (`content/capture.js`, paginate; разбор в `content/extract.js`).
   Прокрутка не годится: фоновую, свёрнутую или закрытую другим окном вкладку
   Chrome не отрисовывает, и лента не подгружается (1 пост вместо 13, проверка
   12.10.2026). doc_id запроса, переменные, курсор и токены берутся со
   страницы при каждом визите, ничего не зашито. Дозапрос останавливается на
   постах старше двух суток.
4. Отправляет посты (`POST .../result/`). Бэкенд сохраняет их как публикации
   целевого аккаунта, дальше обычная обработка. Паузу до следующего источника
   (45 до 120 секунд) задаёт сервер, каждый источник проверяется раз в час,
   закрытые группы раз в сутки.

Куки и токены Facebook из браузера не уходят: на сервер идут посты и id
аккаунта (`c_user`) для журнала.

Серверная часть: `apps/domain/parsing/services/facebook_bridge.py`,
`apps/domain/parsing/facebook_bridge_views.py`, состояние:
`python manage.py facebook_bridge_status`.

## Установка

1. **Профиль Chrome.** Отдельный профиль под Facebook (не личный). Войти на
   facebook.com аккаунтом для мониторинга, пройти проверку, если просит. В
   закрытые группы из списка аккаунт должен вступить.
2. **Папка расширения.** Скопировать `extension/fb-bridge` в
   `C:\FB-Bridge\extension` (стабильный путь вне репозитория).
3. **Загрузка.** `chrome://extensions` → «Режим разработчика» → «Загрузить
   распакованное расширение» → `C:\FB-Bridge\extension`. Закрепить иконку.
4. **Настройки расширения:** адрес `https://app.mediascanner.kz`, токен
   (значение `FACEBOOK_BRIDGE_TOKENS` из переменных CI бэкенда), метка ПК,
   аккаунт Facebook (необязательно, для себя). «Сохранить» → «Проверить» →
   «Сервер: на связи, токен принят» и «Facebook: вход выполнен». Первая
   проверка начнётся в течение минуты («Собрать сейчас» в окне расширения
   запускает её сразу). Вкладку facebook.com расширение открывает и
   закрепляет само.
5. **Автозапуск** и отключение сна Windows, как у IG Bridge: Chrome с этим
   профилем в автозагрузке, «Продолжать работу фоновых сервисов после закрытия
   Google Chrome» включено.
6. **Обновление:** заменить файлы в `C:\FB-Bridge\extension` →
   `chrome://extensions` → «Обновить».

В профиле не выходить из Facebook, не чистить куки, не включать VPN.

## Бейдж на иконке

| Бейдж | Что значит | Что делать |
|---|---|---|
| пусто | работает | ничего |
| `SET` | не настроено | открыть настройки, вписать токен |
| `IN` | вход в Facebook потерян | войти на facebook.com в этом профиле |
| `!` | Facebook просит проверку или ограничил аккаунт | открыть facebook.com, пройти проверку |
| `KEY` | неверный токен | исправить токен в настройках |
| `ERR` | нет связи с сервером | проверить интернет, расширение повторит само |
