# MediaScanner Bridges

Расширения Chrome для сбора соцсетей из браузерного профиля. Каждое ставится отдельно как распакованное расширение.

| Папка | Соцсеть |
|---|---|
| `fb-bridge` | Facebook |
| `tt-bridge` | TikTok |
| `ig-bridge` | Instagram |

## Установка

1. Скачайте репозиторий (Code, Download ZIP) и распакуйте.
2. Откройте `chrome://extensions`, включите «Режим разработчика».
3. «Загрузить распакованное расширение» и выберите нужную папку (`fb-bridge`, `tt-bridge` или `ig-bridge`).
4. Откройте настройки расширения: укажите адрес сервера, токен и метку ПК. Токены в репозитории не хранятся.
5. Войдите в нужную соцсеть в этом же профиле Chrome.

Подробности по каждому расширению в README внутри папки (если есть).
